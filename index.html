Unit 1 - Web Fundamentals and HTML

1. Internet vs Web

The Internet is a global network of connected computers and devices. The Web is a service that runs on the Internet and allows users to access websites and web pages.

Internet Web
Global network of computers Service running on the Internet
Uses many protocols Mainly uses HTTP and HTTPS

2. Static vs Dynamic Websites

Static Website Dynamic Website
Content is mostly fixed Content can change dynamically
Usually uses HTML and CSS Can use server-side programming and databases

3. HTTP, HTTPS and TCP

HTTP stands for HyperText Transfer Protocol. It is used for communication between a browser and a web server.

HTTPS is the secure version of HTTP. It encrypts communication between the browser and server.

TCP stands for Transmission Control Protocol. It provides reliable communication between devices over a network.

4. Client-Side and Server-Side Scripting

Client-side scripting runs in the user's browser. JavaScript is a common example.

Server-side scripting runs on the web server and can process requests, databases and other server operations.

5. Absolute and Relative URLs

An absolute URL contains the complete web address.

Example: https://www.example.com/about.html

A relative URL points to a resource relative to the current page.

Example: about.html

Unit 2 - CSS Core and Box Model

1. Types of CSS

CSS can be applied to HTML using three main methods: Inline, Internal and External CSS.

Type Where Used Example
Inline Inside HTML element style="color:red"
Internal Inside <style> <style>
External Separate CSS file style.css

2. CSS Selectors

  • Element Selector: p { }
  • Class Selector: .box { }
  • ID Selector: #header { }
  • Universal Selector: * { }
  • Grouping Selector: h1, h2 { }

4. CSS Box Model

Every HTML element can be represented as a box. The CSS box model contains four parts:

Border
Padding
Content
  • Content - actual content of the element
  • Padding - space around the content
  • Border - line surrounding the padding
  • Margin - space outside the border

Width Calculation

Total Width = Content Width + Left Padding + Right Padding + Left Border + Right Border + Left Margin + Right Margin

Height Calculation

Total Height = Content Height + Top Padding + Bottom Padding + Top Border + Bottom Border + Top Margin + Bottom Margin
