HTML

HTML stands for HyperText Markup Language. It is used to create and structure the content of web pages.

1. Internet and World Wide Web

The Internet is a worldwide network of connected computers and devices that communicate with each other.

The World Wide Web, also called the Web, is a service that works on the Internet. It contains websites and web pages that can be accessed using web browsers.

Internet Web
Global network of computers Collection of websites and web pages
Provides many services One service available through the Internet

2. Static and Dynamic Websites

A static website contains fixed content. The content generally remains the same until the developer changes the HTML files.

A dynamic website can generate different content according to user input, database information or other conditions.

Static Website Dynamic Website
Fixed content Content can change
Usually simple Can use databases and server-side programs

3. HTTP, HTTPS and TCP

HTTP stands for HyperText Transfer Protocol. It is used for communication between a web browser and a web server.

HTTPS stands for HyperText Transfer Protocol Secure. It provides encrypted communication between the browser and server.

TCP stands for Transmission Control Protocol. It helps provide reliable communication between devices over a network.

4. Client-Side and Server-Side Scripting

Client-side scripting runs mainly in the user's web browser. JavaScript is a common example of client-side scripting.

Server-side scripting runs on the web server. It can process requests, work with databases and generate responses.

Client-Side Server-Side
Runs in browser Runs on server
Example: JavaScript Example: PHP, Python, Node.js

5. Absolute and Relative URLs

A URL is an address used to locate a resource on the Web.

An absolute URL contains the complete web address. 

https://www.example.com/about.html

A relative URL gives the location relative to the current webpage.

CSS

CSS stands for Cascading Style Sheets. It is used to control the appearance, layout and design of HTML elements.

1. Types of CSS

CSS can be added to HTML documents in three main ways: inline CSS, internal CSS and external CSS.

Type Description Example
Inline CSS Written inside the style attribute. <p style="color:red">
Internal CSS Written inside the style tag. <style> p { color:red; } </style>
External CSS Written in a separate CSS file. style.css

2. CSS Selectors

Selectors are used to select HTML elements that we want to style.

Selector Example Use
Element p Selects all paragraph elements.
Class .container Selects elements having the class.
ID #home Selects an element with a specific ID.
Universal * Selects all elements.
Grouping h1, h2 Selects multiple elements.

3. Important CSS Properties

Background Properties

Property Use
background-color Sets background color.
background Sets background properties.

Text Properties

Property Use
color Sets text color.
text-align Sets text alignment.
text-decoration Adds underline or other text decoration.

Font Properties

Property Use

font-size Sets font size.

List Properties

Property Use

Border Properties

Property Use

border-radius Rounds the corners.

Margin and Padding

Property Use
margin Creates space outside an element.
padding Creates space inside an element.

Display and Visibility

Property Use
display Controls how an element is displayed.
visibility Controls whether an element is visible.

4. CSS Box Model

The CSS Box Model describes how every HTML element is represented as a rectangular box.

Margin
Border
Padding
Content

The four main parts of the CSS Box Model are:

  1. Content: Actual text, image or other content.
  2. Padding: Space between content and border.
  3. Border: Boundary around the element.
  4. Margin: Space outside the border.

Box Model Calculation

For content-box:

Total Width =
Content Width
+ Left Padding
+ Right Padding
+ Left Border
+ Right Border
+ Left Margin
+ Right Margin

Total Height =
Content Height
+ Top Padding
+ Bottom Padding
+ Top Border
+ Bottom Border
+ Top Margin
+ Bottom Margin

The box-sizing property can also be used to control how the width and height of an element are calculated.
